# Ebenen kombinieren und überblenden

Lerne, wie du einen Produktausschnitt und eine Hintergrund-Szene als separate Ebeneneingaben Stapel. Passe Mischmodus und Beleuchtungsknoten an, bis sich die Komposition als eine Aufnahme ausliest. [Vorlage für Composite- und Mischebenen öffnen](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:6ab4c3c7-ead2-5fa5-9441-75b7a362ce11).

[!BADGE Branchenbeispiele]{type=Informative tooltip="Beispiele aus der Branche"}

* **Getränke** - Kombinieren Sie eine neue Dose zu einer Beach-Lifestyle-Szene für eine Sommerkampagne, ohne ein Flugzeug zu fliegen.
Fotomannschaft an einen Ort entsenden.
* **Einzelhandel** - Überblendung eines Produktausschnitts in einen saisonalen Lifestyle-Hintergrund für ein Homepage-Banner.
* **Reise** - Fügen Sie einen Zielhintergrund hinter einer Produktaufnahme für eine Co-Branding-Aktion zusammen.

>[!TIP]
>
>**Bevor Sie beginnen** - Um optimale Ergebnisse zu erzielen, passen Sie diese Vorlage an Ihr eigenes Branding, Produkt und Ihren eigenen Workflow an. Tauschen Sie Ihre Referenzbilder, Eingabeaufforderungen und Texte ein, bevor Sie eine Ausgabe verwenden.
