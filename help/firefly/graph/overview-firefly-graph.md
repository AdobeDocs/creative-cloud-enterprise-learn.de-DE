# Erste Schritte mit Firefly Graph

Wenn du schon einmal ein generatives KI-Tool verwendet hast, bist du wahrscheinlich daran gewöhnt, eine Eingabeaufforderung einzugeben, ein Ergebnis zu erhalten und beim nächsten Mal von vorne anzufangen, wenn du etwas Ähnliches brauchst. &quot;Firefly Graph&quot; funktioniert anders. Anstelle einer einzelnen Eingabeaufforderung erstellen Sie einen Graf: einen visuellen, schrittweisen Arbeitsablauf, bei dem jede Eingabe, Transformation und Ausgabe verbunden und zusammen gespeichert wird. Diese Seite führt Sie durch alle Elemente, die Sie zum Erstellen Ihres ersten Grafen benötigen: die grundlegenden Konzepte kennen, einen ersten Arbeitsablauf Schritt für Schritt sowie eine Bibliothek gebrauchsfertiger Vorlagen, die du direkt öffnen und anpassen kannst.

>[!TIP]
>
>Stelle es dir wie ein Rezept vor, anstatt wie eine einzige Mahlzeit. Sobald du einen Graf erstellt hast, kannst du ihn abgeben, auf neuen Eingängen erneut ausführen oder einen Schritt ändern, sodass alles Downstream automatisch aktualisiert wird.
